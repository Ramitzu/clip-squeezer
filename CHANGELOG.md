# Changelog

## 1.0.1 - 2026-11-09

- Fixed the finish message saying "nothing to compress" after a real compress.
- Clip lengths now appear as soon as the first-time ffmpeg download finishes.

## 1.0.0 - 2026-11-09

First public release.

- Shrink clips to a target size with two-pass H.264 encoding.
- Discord size presets, custom sizes, and three speed settings.
- Drag and drop, batches and whole folders.
- Resolution and frame rate drop only as far as the budget requires.
- Standalone Windows build. FFmpeg is downloaded once, after you agree.
